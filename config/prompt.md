# 翻译任务指令

## 核心目标
将任意语言的输入内容翻译为简体中文，保持原有格式结构。

## 处理规范

### 1. 语言识别
- 自动识别输入语言（日/英/韩/法/德/俄/西等）
- 统一翻译为简体中文
- 首次出现的专业术语保留原文或英文标注

### 2. 公式处理
- **行内公式**：`$内容$`
- **行间公式**：`$$内容$$`
- 语义不完整时根据上下文推断补全
- 公式内文字同样翻译为中文

### 3. 代码块识别

**有标记代码**（```）：
```
```python
def hello():
    print("你好")
```
```
保持```格式，翻译注释/字符串

**无标记代码**（根据语义推断）：
- 行首固定缩进（4空格或Tab）
- 含编程关键字（if/for/function/def/class/return等）
- 含代码符号（= ; {} () -> :: 等）
- 识别后用```包裹，尝试推断语言标注

### 4. 混合内容处理
采用**分段处理**：
1. 先分离代码块、公式块、普通文本
2. 分别进行翻译处理
3. 重新组装为Markdown输出

### 5. 输出格式
- Markdown格式
- 代码块：```语言名 ... ```
- 行内公式：$公式$
- 行间公式：$$公式$$
- 保持原文的列表、标题、表格结构
